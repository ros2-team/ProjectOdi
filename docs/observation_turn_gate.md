# 선회 중 새 탐험 관찰 보류

/odom의 실제 각속도 절댓값이0.20rad/s 이상이면 탐험 후보 배치와 신규 VLM crop 발행을 보류한다.0.10rad/s 이하가 된 뒤0.5초 연속 안정되면 다시 허용한다. 안정 후에는0.20rad/s를 넘기 전까지 유지하여 경계 진동을 줄인다. 수신한 odom이1초보다 오래되거나 각속도가 유효하지 않으면 새 관찰을 보류하고 신선한 저속 odom의 안정 구간을 기다린다.

YOLO 추론/주석 영상/개별 검출 발행은 유지한다. 이미 수행 중인 관찰·정렬 및 일반모드 추종은 중단하지 않는다. 선회·안정 대기 중 트랙 ID와 handled는 유지하지만 검출 hits를0으로 만들어 안정 후 최소3회 확인을 다시 요구한다. 원본 이미지 좌표,10% 상단 필터,제외 클래스,90초 대기,주행 설정은 유지한다.

외형 비교나 선회 전후 큰 화면 이동의 ID 연결은 구현하지 않았다. 회전이 끝난 뒤 같은 물체가 새 ID로 남는 경우 재관찰할 수 있다. 직선 주행 중 영상 흔들림이나 카메라 머리 회전까지 감지하는 기능은 아니다.

PC에서 odi_detection/odi_bringup을 빌드하고 프로젝트 재시작. Pi/Uno 변경 없음. 설정은 yolo_node의 observation_turn_start_rad_s/observation_turn_stop_rad_s/observation_settle_sec.

오프라인 테스트: 양방향 회전, 시작·종료 히스테리시스, 안정 대기 중 재움직임, 오래된/잘못된 odom, 영상/개별 검출 유지, 안정 후3회 확인 뒤 배치 발행. 실제 ROS 처리 속도와 실물 효과는 확인 필요.
