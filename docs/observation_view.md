# 실습장 관찰 범위 조정

- 탐험 신뢰도: 0.35, 최소 박스 면적: 화면의 1%, 최소 확인: 3회.
- 제외 클래스: person, chair, tv, laptop. YOLO 원본 주석 영상에는 박스가 남지만 탐험 후보와 일반모드 검출 업데이트에서 제외한다.
- ignored_top_ratio: 0.30. 박스 중심이 상단 30%에 있으면 제외한다. 경계를 걸친 물체는 중심 기준으로 처리하며 원본 이미지와 좌표는 유지한다.
- 실제로 선택한 후보만 handled로 기록한다. 선택하지 않은 같은 배치의 후보는 이후 관찰할 수 있다.
- 일반모드의 자체 신뢰도/대상 클래스 조건은 유지한다.

## 카메라

Uno TILT_HOME과 PC normal_node tilt_home을 모두 65에서 70으로 변경했다. 기존 tilt_sign=+1(화면 아래 물체로 향할 때 각도 증가)에 근거한 +5도 조정이며, 실제 장착 방향은 영상으로 확인해야 한다. 반대로 올라가면 두 값을 함께 수정한다. PC 빌드만으로는 탐험 중 정면이 바뀌지 않으므로 Uno 펌웨어 업로드도 필요하다.

카메라 물리 각도 변경 시 기존 카메라-LiDAR 외부 보정/TF가 더 이상 맞지 않을 수 있다. 거리 필터 정확도는 재보정 후 확인한다. 화면 영역 필터는 실제 거리나 실습장 경계를 판별하지 않는다. 신발과 라면은 기본 COCO 모델의 독립 클래스가 아니다.

## 검증

관찰 영역 경계/제외 클래스/소형 물체 반복 검출 테스트 통과. 기존 세션 및 현장 회귀 테스트 통과(선택 의존성 없는 항목만). 펌웨어 C++ 스텁 통과. 전체 테스트는 환경의 pymysql 미설치로 일기 아카이브 테스트를 실행하지 못했다. 실제 ROS 빌드와 카메라 각도/인식 확인은 로봇에서 수행해야 한다. 주행 컨트롤러는 이번 변경 대상이 아니다.
