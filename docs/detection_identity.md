# 검출 이름 변경과 재관찰 대기

탐험 reobserve_cooldown_sec를90초로 변경했다. 첫 조우 결과 시점부터 계산하며 일반모드 cooldown_sec는 변경하지 않는다. 기존0.5m 위치 조건은 확대하지 않는다.

최근0.75초 내 박스와 IoU0.6 이상 겹치면 클래스가 달라도 기존 ID를 연결한다. 이전 트랙 후보나 새 박스 후보가 여러 개이면 클래스 간 연결을 하지 않는다. 일대일 연결 및 handled 상태를 유지하며 제외 클래스 필터는 최신 클래스에 그대로 적용한다. 원래 같은 클래스의 IoU0.3 연결은 유지한다.

이는 짧은 시간의 이름 흔들림 완화이며 실제 개체 식별이나 외형 비교가 아니다. 같은 위치에서 다른 물체가 빠르게 교체되면 잘못 연결될 수 있다. 선회 중 화면 반대편으로 이동해 겹치지 않는 경우, 긴 가림이나 클래스 변경은 여전히 새 ID를 만들 수 있다. 장소 차단 범위를 늘리지 않는다.

테스트: 이름 변경 뒤 handled 유지, 다른 위치/긴 간격의 다른 클래스 분리, 여러 박스 중복 연결 방지,90초 만료 및 세션 초기화. 현장 실제 중복 감소는 확인 필요.
