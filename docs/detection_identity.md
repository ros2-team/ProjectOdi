# 검출 이름 변경과 재관찰 대기

탐험 reobserve_cooldown_sec를90초로 변경했다. 첫 조우 결과 시점부터 계산하며 일반모드 cooldown_sec는 변경하지 않는다. 기존0.5m 위치 조건은 확대하지 않는다.

최근 3초 내 박스와 IoU 0.3 이상 겹치고, 이전 트랙과 현재 박스가 서로 유일한 연결 후보이면 이름이 달라도 기존 ID를 유지한다. 후보 수는 현재 프레임 처리 전 트랙 전체를 기준으로 확인한다. 관찰 처리 여부(handled)도 유지하므로 이름이 바뀐 뒤 원래 ID로 첫 조우 결과가 늦게 도착해도 반영된다. 제외 클래스와 관찰 대상 클래스 사이에는 이 연결을 적용하지 않는다. 같은 클래스의 기존 IoU 0.3 연결 및 선회 시 동일 클래스 연결은 유지한다.

이는 짧은 시간의 이름 흔들림 완화이며 실제 개체 식별이나 외형 비교가 아니다. 같은 위치에서 다른 물체가 빠르게 교체되면 잘못 연결될 수 있다. 선회 중 화면 반대편으로 이동해 겹치지 않는 경우, 긴 가림이나 클래스 변경은 여전히 새 ID를 만들 수 있다. 장소 차단 범위를 늘리지 않는다.

테스트: 검출 간격 1.2초 및 IoU 약 0.48의 명칭 변경 뒤 handled 유지, 늦게 도착한 결과 반영, 다른 위치/3초 초과 간격의 다른 클래스 분리, 양방향 후보 중복 연결 방지, 제외 클래스 분리, 90초 만료 및 세션 초기화. 현장 실제 중복 감소는 확인 필요.
